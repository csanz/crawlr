# Simple Slither Game

A simple 3D game built with Three.js and Rapier physics where you control a character that collects coins and grows a snake-like tail.

## Features

- 3D environment with physics-based interactions
- Player movement with keyboard controls
- Collectable coins that spawn randomly
- Dynamic tail that grows as you collect coins
- Physics-based interactions with environment

## Tail Implementation

The game features a dynamic tail system inspired by the classic Snake game:

- As you collect coins, your character grows a tail
- Each tail segment follows the path of the player with a delay
- Tail segments have a subtle wiggle effect for liveliness
- Custom shader and geometry for visually appealing segments
- Particle effects when new segments are added

## Technical Details

This game uses:
- Three.js for 3D rendering
- Rapier physics for realistic interactions
- Modular code architecture for maintainability
- Custom shader effects and procedurally generated textures

## Documentation

For more details on the implementation, see:
- [Tech Design: Slither Tail](docs/Tech%20Design%20Slither%20Tail.md) - Technical design of the tail system
- [Code Organization](docs/Code%20Organization.md) - Overview of the code structure

## Controls

- WASD or Arrow Keys: Move player
- Shift: Run
- Mouse: Camera control

## Development

The codebase is structured for easy extension:
- `app.js` - Main entry point
- `libs/` - Modular components for different game systems
- `public/assets/` - Game assets and textures

# Code Organization

## Structure Overview

This codebase is organized into modular components, with core game systems separated into libraries under the `libs/` directory. The main entry point is `app.js`, which imports and initializes these systems.

## Key Modules

### Core Game Structure
- **app.js**: Main entry point that initializes the game world and components
- **libs/GameLoop.js**: Manages the main game loop and coordinates system updates

### Rendering & Visuals
- **libs/RendererSetup.js**: Configures the Three.js renderer
- **libs/CameraSetup.js**: Sets up camera and orbit controls
- **libs/Lighting.js**: Handles scene lighting
- **libs/SkySphere.js**: Creates the game's sky background
- **libs/TextureLoader.js**: Utility for loading textures

### Physics & Game Objects
- **libs/PhysicsConfig.js**: Contains physics-related configuration values
- **libs/Ground.js**: Creates the ground plane
- **libs/Player.js**: Manages player creation and movement
- **libs/Coin.js**: Defines coin objects
- **libs/CoinManager.js**: Handles spawning and managing coins
- **libs/PushableBlock.js**: Implements pushable block mechanics

### Game Systems
- **libs/InputHandler.js**: Processes keyboard/mouse input
- **libs/CollisionHandler.js**: Detects and handles object collisions
- **libs/Sound.js**: Manages game audio
- **libs/Tail.js**: Implements the snake-like tail system

## Data Flow

1. **Initialization**: app.js initializes all systems and game objects
2. **Main Loop**: GameLoop.js coordinates the update cycle:
   - Process physics (Rapier)
   - Handle collisions
   - Update player movement
   - Update visual positions
   - Update tail
   - Render frame

## System Interactions

- **Player → Tail**: Player movement is recorded in position history for tail to follow
- **Coins → Tail**: When coins are collected, a new tail segment is added
- **Input → Player**: User input controls player movement
- **Physics → Visuals**: Physics engine positions are applied to Three.js meshes

# Technical Design: Slither Tail Implementation

## Overview

This document outlines the implementation of a snake-like tail system for our game, where the player's tail grows incrementally as they collect gold coins.

## Core Mechanics

### Position History Buffer

- Maintain an array of past player positions
- Record player positions each frame
- Limit history length based on maximum expected tail segments

### Tail Segment Management

- Each tail segment follows a position from the history buffer
- Segments are spaced by a configurable number of frames
- New segments are added when gold coins are collected

### Visual Implementation

- Each segment is a separate mesh
- Segments follow with a slight delay for a natural snake-like movement
- Optional: Add scaling, rotation, and wiggle effects for visual appeal

## Implementation Details

### Data Structures

```js
// Position history array
let positionHistory = [];
const maxHistoryLength = 1000;

// Tail segments array
let tailSegments = [];
const tailSegmentSpacing = 10; // frames between segments
```

### Key Functions

#### Position History

```js
function updatePositionHistory() {
  positionHistory.unshift(playerMesh.position.clone());
  if (positionHistory.length > maxHistoryLength) {
    positionHistory.pop();
  }
}
```

#### Adding Tail Segments

```js
function addTailSegment() {
  const segmentGeometry = new THREE.BoxGeometry(0.8, 0.8, 0.8);
  const segmentMaterial = new THREE.MeshStandardMaterial({ color: 0x00ff00 });
  const segmentMesh = new THREE.Mesh(segmentGeometry, segmentMaterial);

  segmentMesh.position.copy(playerMesh.position);
  scene.add(segmentMesh);
  tailSegments.push(segmentMesh);
}
```

#### Updating Tail Positions

```js
function updateTailPositions() {
  for (let i = 0; i < tailSegments.length; i++) {
    const historyIndex = (i + 1) * tailSegmentSpacing;
    if (positionHistory[historyIndex]) {
      tailSegments[i].position.lerp(positionHistory[historyIndex], 0.4);
    }
  }
}
```

#### Integration with Coin Collection

```js
function onCoinCollected(coin) {
  scene.remove(coin);
  addTailSegment();
}
```

## Enhancements

### Segment Orientation

```js
if (positionHistory[historyIndex + 1]) {
  tailSegments[i].lookAt(positionHistory[historyIndex + 1]);
}
```

### Animated Wiggle

```js
tailSegments[i].position.x += Math.sin(performance.now() * 0.001 + i) * 0.05;
```

### Tail Tapering

```js
segmentMesh.scale.setScalar(1 - i * 0.03);
```

## Integration with Current Codebase

The implementation will integrate with our existing Three.js and Rapier physics setup. The tail segments will be visual-only with no physics colliders to maximize performance.

/**
 * Sets up the perspective camera for the scene.

 * @param {number} height - The height of the viewport.

export function setupCamera(width, height) {
    const camera = new THREE.PerspectiveCamera(75, width / height, 0.1, 1000);
    camera.position.set(0, 3, 5); // Initial camera position
    // camera.lookAt(0, 0, 0); // Look at the center (will be added to scene later)
    return camera;
}

/**
 * Sets up OrbitControls for the camera.
 * @param {THREE.PerspectiveCamera} camera - The camera to control.
 * @param {HTMLCanvasElement} domElement - The renderer's canvas element.
 * @returns {OrbitControls} The configured controls instance.
 */
export function setupOrbitControls(camera, domElement) {
    const controls = new OrbitControls(camera, domElement);
    controls.enableDamping = false; // Explicitly disable
    // controls.dampingFactor = 0.05;
    // controls.screenSpacePanning = false; // Optional: adjust panning behavior
    controls.minDistance = 5; // Set zoom limits once
    controls.maxDistance = 20;
    // controls.maxPolarAngle = Math.PI / 2; // Optional: prevent looking from below ground
    return controls;
}

/**
 * Updates the camera to follow the player mesh.
 * @param {THREE.PerspectiveCamera} camera - The camera to update.
 * @param {OrbitControls} controls - The OrbitControls instance.
 * @param {THREE.Mesh} playerMesh - The player mesh to follow.
 * @param {THREE.Vector3} lookAtOffset - Offset from player position for the camera target.
 */
export function updateCameraFollow(camera, controls, playerMesh, cameraLookAtOffset) {
    const targetLookAt = new THREE.Vector3().copy(playerMesh.position).add(cameraLookAtOffset);
    camera.position.lerp(targetLookAt, 0.1); // Keep this lerp for now as requested
    // Make camera look at the slightly elevated target point
    camera.lookAt(targetLookAt);  
    // Keep vertical tilt limited
    controls.minPolarAngle = Math.PI / 6; // looking down ~45°
    controls.maxPolarAngle = Math.PI / 4.5; // maybe ~72°, slightly lower than horizontal
    // Allow zooming in/out
    controls.minDistance = 14;   // close enough
    controls.maxDistance = 40;  // far enough to see effect
    controls.target.copy(targetLookAt); // Set target directly
    controls.update(); 
}

import * as THREE from 'three';
import * as RAPIER from '@dimforge/rapier3d';
// Import renamed config constants
import { COIN_RADIUS, COIN_COLOR } from './PhysicsConfig.js';

/**
 * Creates a coin item (visual mesh and physics body).
 * @param {THREE.Scene} scene - The Three.js scene.
 * @param {RAPIER.World} world - The Rapier physics world.
 * @param {THREE.Vector3} position - The starting position for the coin.
 * @returns {{mesh: THREE.Mesh, body: RAPIER.RigidBody}} 
 */
export function createCoin(scene, world, position) {
    // Visual representation - a full circular coin (TorusGeometry)
    // TorusGeometry params: radius, tube radius, radial segments, tubular segments
    const geometry = new THREE.TorusGeometry(COIN_RADIUS, COIN_RADIUS/4, 16, 32);
    
    // Create a material that will glow
    const material = new THREE.MeshStandardMaterial({ 
        color: COIN_COLOR,
        emissive: COIN_COLOR,
        emissiveIntensity: 2,
        roughness: 0.3,
        metalness: 0.8
    });
    
    const mesh = new THREE.Mesh(geometry, material);
    
    // Rotate to make the coin face up (flat side showing)
    mesh.rotation.x = Math.PI / 2;
    
    mesh.position.copy(position);
    
    // Add the coin to layer 1 for the bloom effect
    mesh.layers.enable(1);
    
    scene.add(mesh);

    // Physics body
    const bodyDesc = RAPIER.RigidBodyDesc.dynamic().setTranslation(position.x, position.y, position.z);
    const body = world.createRigidBody(bodyDesc);
    const colliderDesc = RAPIER.ColliderDesc.ball(COIN_RADIUS)
        // Explicitly enable collision events
        .setActiveEvents(RAPIER.ActiveEvents.COLLISION_EVENTS)
        // Explicitly allow collisions with ALL types
        .setActiveCollisionTypes(RAPIER.ActiveCollisionTypes.ALL);
        
    // Create the collider and immediately set its userData
    const collider = world.createCollider(colliderDesc, body);
    collider.userData = { type: 'coin', mesh }; // Store mesh reference here too if needed

    return { mesh, body }; // Return mesh and body
}

import * as THREE from 'three';
import { createCoin } from './Coin.js';
import { playCoinCollect } from './Sound.js';
import { addTailSegment } from './Tail.js';
import { MAX_COINS, COIN_DROP_HEIGHT, COIN_SPAWN_AREA_XZ } from './PhysicsConfig.js';

/**
 * Creates and manages coins in the game world
 */
export class CoinManager {
    constructor(scene, world) {
        this.scene = scene;
        this.world = world;
        this.activeCoins = new Map(); // Tracks active coins by body handle
        this.coinsToProcessPostCollision = []; // Queue for cleanup
        this.spawnPosition = new THREE.Vector3();
    }

    /**
     * Spawns new coins if below the maximum limit
     */
    spawnCoins() {
        if (this.activeCoins.size < MAX_COINS) { 
            const randomX = (Math.random() - 0.5) * COIN_SPAWN_AREA_XZ;
            const randomZ = (Math.random() - 0.5) * COIN_SPAWN_AREA_XZ;
            this.spawnPosition.set(randomX, COIN_DROP_HEIGHT, randomZ); 
            
            const { mesh, body } = createCoin(this.scene, this.world, this.spawnPosition); 
            this.activeCoins.set(body.handle, { mesh, body }); 
        }
    }

    /**
     * Processes coin collision with player
     * @param {number} coinBodyHandle - The handle of the coin's rigid body
     * @param {THREE.Mesh} coinMesh - The visual mesh of the coin
     * @param {THREE.Vector3} playerPosition - The current player position
     * @returns {boolean} Whether the coin was successfully processed
     */
    processCoinCollection(coinBodyHandle, coinMesh, playerPosition) {
        // Check if we already processed this coin
        if (!this.activeCoins.has(coinBodyHandle) || 
            this.coinsToProcessPostCollision.some(item => item.bodyHandle === coinBodyHandle)) {
            console.log("Failed check: activeCoins map doesn't have handle OR already queued");
            return false;
        }
            
        // Play sound effect
        playCoinCollect(0.8);
        
        // Add a tail segment at the player's current position
        addTailSegment(this.scene, playerPosition);
        
        // Remove visual mesh immediately for responsiveness
        this.scene.remove(coinMesh);
        
        // Queue for physics cleanup
        this.coinsToProcessPostCollision.push({ bodyHandle: coinBodyHandle, mesh: coinMesh });
        
        // Remove from active tracking
        this.activeCoins.delete(coinBodyHandle); 
        
        return true;
    }

    /**
     * Cleans up coins marked for removal
     */
    cleanupCoins() {
        this.coinsToProcessPostCollision.forEach(({ bodyHandle, mesh }) => {
            const body = this.world.getRigidBody(bodyHandle);
            if (body && body.isEnabled()) {
                console.log("Disabling coin body handle:", bodyHandle);
                body.setEnabled(false);
            }
             
            if(mesh.parent) {
                this.scene.remove(mesh);
            }
        });
        this.coinsToProcessPostCollision = [];
    }

    /**
     * Updates positions of active coins
     */
    updateCoinPositions() {
        this.activeCoins.forEach((coinData, handle) => { 
            const body = this.world.getRigidBody(handle);
            if (body) {
                const pos = body.translation();
                coinData.mesh.position.set(pos.x, pos.y, pos.z);
            } 
        });
    }
}

export function createCollectible(scene, world, position) {

    // Physics body

export class CollisionHandler {
    constructor(world, coinManager) {
        this.world = world;
        this.coinManager = coinManager;
    }

    /**
     * Process collision events from the event queue
     * @param {EventQueue} eventQueue - Rapier physics event queue
     * @param {THREE.Mesh} playerMesh - Player mesh for position reference
     */
    processCollisions(eventQueue, playerMesh) {
        eventQueue.drainCollisionEvents((handle1, handle2, started) => {
            // Get the colliders involved
            const collider1 = this.world.getCollider(handle1);
            const collider2 = this.world.getCollider(handle2);

            // Skip if either collider doesn't exist
            if (!collider1 || !collider2) {
                return; 
            }

            // Get types from collider userData
            const type1 = collider1?.userData?.type;
            const type2 = collider2?.userData?.type;

            // Check for player-coin collisions
            if ((type1 === 'player' && type2 === 'coin') || (type2 === 'player' && type1 === 'coin')) {
                this.handlePlayerCoinCollision(collider1, collider2, type1, type2, started, playerMesh);
            }
            
            // Add other collision type handlers as needed
        });
    }

    /**
     * Handle collision between player and coin
     * @private
     */
    handlePlayerCoinCollision(collider1, collider2, type1, type2, started, playerMesh) {
        if (!started) return;
        
        console.log("Player-coin collision detected");
        
        // Determine which collider is the coin
        const coinCollider = (type1 === 'coin') ? collider1 : collider2;
        
        // Get the coin's body and mesh
        const parentBody = coinCollider?.parent();
        const coinBodyHandle = parentBody?.handle;
        const coinUserData = coinCollider?.userData;
        const coinMesh = coinUserData?.mesh;
        
        // Process the coin collection if we have all required data
        if (coinBodyHandle != null && coinMesh) {
            this.coinManager.processCoinCollection(
                coinBodyHandle, 
                coinMesh, 
                playerMesh.position.clone()
            );
        } else {
            console.log("Failed to process coin: missing body handle or mesh");
        }
    }

    context.beginPath();
    context.arc(size * 0.7, size * 0.4, size * 0.1, 0, Math.PI * 2);

    const texture = new THREE.CanvasTexture(canvas);

function createPlayerGeometry() {
    // Create a slightly rounded box geometry for the player
    const geometry = new THREE.BoxGeometry(1, 1, 1, 2, 2, 2);
    
    // Get position attribute to modify vertices
    const positions = geometry.attributes.position;
    
    // Slightly round the corners by pushing vertices outward
    for (let i = 0; i < positions.count; i++) {
        const x = positions.getX(i);
        const y = positions.getY(i);
        const z = positions.getZ(i);
        
        // Calculate normalized direction from center
        const length = Math.sqrt(x*x + y*y + z*z);
        const normalizedX = x / length;
        const normalizedY = y / length;
        const normalizedZ = z / length;
        
        // Push vertices slightly outward for rounded effect (more on edges/corners)
        positions.setXYZ(
            i,
            x + normalizedX * TAIL_SEGMENT_ROUNDNESS,
            y + normalizedY * TAIL_SEGMENT_ROUNDNESS,
            z + normalizedZ * TAIL_SEGMENT_ROUNDNESS

    cameraRight.y = 0;

// Sound library for game audio effects

// Initialize audio context
let audioContext;
const sounds = {};

// Initialize sound system
export function initSoundSystem() {
    // Create audio context on first user interaction
    if (!audioContext) {
        audioContext = new (window.AudioContext || window.webkitAudioContext)();
        loadSounds();
    }
    return audioContext;
}

// Load all game sounds
function loadSounds() {
    loadSound('coinCollect', '/coin-collect.mp3');
    // Add more sounds here as needed
}

// Load a single sound
function loadSound(name, url) {
    fetch(url)
        .then(response => response.arrayBuffer())
        .then(arrayBuffer => audioContext.decodeAudioData(arrayBuffer))
        .then(audioBuffer => {
            sounds[name] = audioBuffer;
            console.log(`Sound loaded: ${name}`);
        })
        .catch(error => console.error(`Error loading sound ${name}:`, error));
}

// Play a loaded sound with optional volume (0.0 to 1.0)
export function playSound(name, volume = 1.0) {
    if (!audioContext) {
        console.warn('Audio context not initialized. Call initSoundSystem first.');
        return;
    }
    
    const sound = sounds[name];
    if (!sound) {
        console.warn(`Sound "${name}" not loaded yet`);
        return;
    }
    
    const source = audioContext.createBufferSource();
    source.buffer = sound;
    
    // Create gain node for volume control
    const gainNode = audioContext.createGain();
    gainNode.gain.value = volume;
    
    // Connect nodes: source -> gain -> destination
    source.connect(gainNode);
    gainNode.connect(audioContext.destination);
    
    // Play the sound
    source.start(0);
    
    return source; // Return source for potential future control
}

// Specific function for coin collection sound
export function playCoinCollect(volume = 1.0) {
    return playSound('coinCollect', volume);
}

import * as THREE from 'three';
import { loadTexture } from './TextureLoader.js';
import { 
    TAIL_SEGMENT_SPACING, 
    TAIL_SEGMENT_COLOR, 
    TAIL_MAX_SEGMENTS, 
    TAIL_WIGGLE_AMOUNT,
    TAIL_FOLLOW_SPEED,
    TAIL_SCALE_FACTOR,
    TAIL_MIN_SCALE,
    TAIL_SEGMENT_ROUNDNESS
} from './PhysicsConfig.js';

// Data structures for tail management
let positionHistory = [];
let tailSegments = [];
const maxHistoryLength = 1000; // Maximum length of position history buffer
let tailMaterial = null;

/**
 * Creates a procedural texture for tail segments
 * @returns {THREE.Texture} The generated texture
 */
function createProceduralTailTexture() {
    const size = 256;
    const canvas = document.createElement('canvas');
    canvas.width = size;
    canvas.height = size;
    const context = canvas.getContext('2d');
    
    // Create gradient background
    const gradient = context.createLinearGradient(0, 0, size, size);
    gradient.addColorStop(0, '#00cc99');
    gradient.addColorStop(1, '#009977');
    context.fillStyle = gradient;
    context.fillRect(0, 0, size, size);
    
    // Draw pattern of circles
    context.fillStyle = 'rgba(255, 255, 255, 0.1)';
    const circleSize = 16;
    const spacing = 32;
    
    for (let x = spacing / 2; x < size; x += spacing) {
        for (let y = spacing / 2; y < size; y += spacing) {
            context.beginPath();
            context.arc(x, y, circleSize / 2, 0, Math.PI * 2);
            context.fill();
        }
    }
    
    // Create texture from canvas
    const texture = new THREE.CanvasTexture(canvas);
    texture.wrapS = THREE.RepeatWrapping;
    texture.wrapT = THREE.RepeatWrapping;
    
    return texture;
}

/**
 * Creates a custom geometry for tail segments
 * @returns {THREE.BufferGeometry} The tail segment geometry
 */
function createTailSegmentGeometry() {
    // Create a slightly rounded box geometry for the tail segments
    const geometry = new THREE.BoxGeometry(0.8, 0.8, 0.8, 2, 2, 2);
    
    // Get position attribute to modify vertices
    const positions = geometry.attributes.position;
    
    // Slightly round the corners by pushing vertices outward
    for (let i = 0; i < positions.count; i++) {
        const x = positions.getX(i);
        const y = positions.getY(i);
        const z = positions.getZ(i);
        
        // Calculate normalized direction from center
        const length = Math.sqrt(x*x + y*y + z*z);
        const normalizedX = x / length;
        const normalizedY = y / length;
        const normalizedZ = z / length;
        
        // Push vertices slightly outward for rounded effect (more on edges/corners)
        positions.setXYZ(
            i,
            x + normalizedX * TAIL_SEGMENT_ROUNDNESS,
            y + normalizedY * TAIL_SEGMENT_ROUNDNESS,
            z + normalizedZ * TAIL_SEGMENT_ROUNDNESS
        );
    }
    
    // Update geometry after modifying
    geometry.computeVertexNormals();
    
    return geometry;
}

/**
 * Initializes the tail system.
 * @param {THREE.WebGLRenderer} renderer - The renderer for texture loading
 * @returns {Object} The tail system instance
 */
export function initTailSystem(renderer) {
    // Create texture and material
    try {
        // Try to load SVG directly first
        const tailTexture = loadTexture('public/assets/tail-texture.svg', renderer);
        tailMaterial = new THREE.MeshStandardMaterial({ 
            map: tailTexture,
            roughness: 0.7
        });
    } catch (e) {
        console.log("Using procedural tail texture (SVG loading failed)");
        // Fall back to procedural texture
        const proceduralTexture = createProceduralTailTexture();
        tailMaterial = new THREE.MeshStandardMaterial({ 
            map: proceduralTexture,
            roughness: 0.7
        });
    }
    
    // Clear any existing segments (in case of reinit)
    positionHistory = [];
    tailSegments = [];
    
    return {
        updatePositionHistory,
        addTailSegment,
        updateTailPositions
    };
}

/**
 * Updates the position history buffer with current player position.
 * @param {THREE.Vector3} playerPosition - Current position of the player
 */
export function updatePositionHistory(playerPosition) {
    // Store a clone to avoid reference issues
    positionHistory.unshift(playerPosition.clone());
    
    // Limit history length
    if (positionHistory.length > maxHistoryLength) {
        positionHistory.pop();
    }
}

/**
 * Creates a visual effect when a tail segment is added.
 * @param {THREE.Scene} scene - The scene
 * @param {THREE.Vector3} position - Position of the effect
 */
function createAddEffectAt(scene, position) {
    // Create a simple particles ring effect
    const particleCount = 15;
    const geometry = new THREE.BufferGeometry();
    const positions = new Float32Array(particleCount * 3);
    
    // Populate positions array with particles in a ring
    for (let i = 0; i < particleCount; i++) {
        const angle = (i / particleCount) * Math.PI * 2;
        const radius = 0.7;
        
        positions[i * 3] = position.x + Math.cos(angle) * radius;     // x
        positions[i * 3 + 1] = position.y;                            // y
        positions[i * 3 + 2] = position.z + Math.sin(angle) * radius; // z
    }
    
    geometry.setAttribute('position', new THREE.BufferAttribute(positions, 3));
    
    // Create particle material with custom color matching tail
    const particleMaterial = new THREE.PointsMaterial({
        color: TAIL_SEGMENT_COLOR,
        size: 0.2,
        transparent: true,
        opacity: 1.0
    });
    
    // Create particles system
    const particles = new THREE.Points(geometry, particleMaterial);
    scene.add(particles);
    
    // Animate and remove
    const startTime = performance.now();
    const animate = () => {
        const elapsedTime = performance.now() - startTime;
        const duration = 700; // milliseconds
        
        if (elapsedTime < duration) {
            const scale = 1 + (elapsedTime / duration) * 2;
            particles.scale.set(scale, scale, scale);
            
            particleMaterial.opacity = 1 - (elapsedTime / duration);
            
            requestAnimationFrame(animate);
        } else {
            // Remove when done
            scene.remove(particles);
            particles.geometry.dispose();
            particleMaterial.dispose();
        }
    };
    
    animate();
}

/**
 * Adds a new tail segment to the player.
 * @param {THREE.Scene} scene - The scene to add the segment to
 * @param {THREE.Vector3} initialPosition - Initial position for the segment
 * @returns {THREE.Mesh} The created tail segment mesh
 */
export function addTailSegment(scene, initialPosition) {
    // Check if we've reached max tail segments
    if (tailSegments.length >= TAIL_MAX_SEGMENTS) {
        console.log("Maximum tail length reached");
        return null;
    }
    
    // Create a custom segment geometry
    const segmentGeometry = createTailSegmentGeometry();
    const segmentMesh = new THREE.Mesh(segmentGeometry, tailMaterial);
    
    // Position at current player position initially
    segmentMesh.position.copy(initialPosition);
    
    // Apply scale based on position in tail (make segments get smaller)
    const scaleFactor = Math.max(TAIL_MIN_SCALE, 1 - tailSegments.length * TAIL_SCALE_FACTOR);
    segmentMesh.scale.setScalar(scaleFactor);
    
    // Add slight rotation to make the tail more interesting
    segmentMesh.rotation.y = Math.random() * Math.PI * 0.25;
    
    // Add shadow casting
    segmentMesh.castShadow = true;
    
    // Add to scene and segment array
    scene.add(segmentMesh);
    tailSegments.push(segmentMesh);
    
    // Create visual effect at the segment position
    createAddEffectAt(scene, initialPosition);
    
    return segmentMesh;
}

/**
 * Updates positions of all tail segments based on position history.
 * @param {boolean} applyWiggle - Whether to apply wiggle effect to segments
 */
export function updateTailPositions(applyWiggle = true) {
    for (let i = 0; i < tailSegments.length; i++) {
        // Calculate history index based on segment position and spacing
        const historyIndex = (i + 1) * TAIL_SEGMENT_SPACING;
        
        // Update position if we have history data for this segment
        if (positionHistory[historyIndex]) {
            // Apply smooth lerp for natural movement
            tailSegments[i].position.lerp(positionHistory[historyIndex], TAIL_FOLLOW_SPEED);
            
            // Optional: Orient segment to look towards next position
            if (positionHistory[historyIndex + 1]) {
                tailSegments[i].lookAt(positionHistory[historyIndex + 1]);
            }
            
            // Optional: Apply wiggle effect - using sin for X and cos for Y for more natural motion
            if (applyWiggle) {
                const time = performance.now() * 0.001;
                tailSegments[i].position.x += Math.sin(time + i) * TAIL_WIGGLE_AMOUNT;
                tailSegments[i].position.y += Math.cos(time * 0.8 + i) * TAIL_WIGGLE_AMOUNT * 0.5;
            }
            
            // Add a slight continuous rotation for more lively appearance
            tailSegments[i].rotation.z += Math.sin(performance.now() * 0.001 + i * 0.5) * 0.01;
        }
    }
}

/**
 * Gets the current number of tail segments.
 * @returns {number} Current tail length
 */
export function getTailLength() {
    return tailSegments.length;
}

/**
 * Resets the tail by removing all segments.
 * @param {THREE.Scene} scene - The scene containing the segments
 */
export function resetTail(scene) {
    // Remove all tail segments from the scene
    tailSegments.forEach(segment => {
        scene.remove(segment);
    });
    
    // Clear arrays
    tailSegments = [];
    positionHistory = [];
}

import * as THREE from 'three';

/**
 * Loads a texture from the given URL.
 * Configures repeat wrapping suitable for ground textures.
 *
 * @param {string} url - The path to the texture image.
 * @param {THREE.WebGLRenderer} renderer - The Three.js renderer instance.
 * @param {number} [repeatX=1] - How many times the texture should repeat horizontally.
 * @param {number} [repeatY=1] - How many times the texture should repeat vertically.
 * @returns {THREE.Texture} The configured texture object.
 */
export function loadTexture(url, renderer, repeatX = 1, repeatY = 1) {
    const loader = new THREE.TextureLoader();
    const texture = loader.load(url);

    // Set wrapping to repeat
    texture.wrapS = THREE.RepeatWrapping;
    texture.wrapT = THREE.RepeatWrapping;

    // Set repetition amount
    texture.repeat.set(repeatX, repeatY);

    // Optional: Improve texture quality
    texture.magFilter = THREE.LinearFilter;
    texture.minFilter = THREE.LinearMipmapLinearFilter;
    // Use the passed renderer instance
    texture.anisotropy = Math.min(16, renderer.capabilities.getMaxAnisotropy());

    return texture;
}
